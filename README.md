# Мини-учёт оплат учебного центра

Проект разработан в рамках тестового задания. Реализует REST API для управления учениками, платежами и автоматического расчета должников за выбранный месяц, а также адаптивный веб-интерфейс.

## Стек технологий
* **Бэкенд:** Node.js, Express, Prisma ORM
* **База данных:** SQLite
* **Интерфейс:** HTML5, Tailwind CSS
